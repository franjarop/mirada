# mirada
Procesamiento de imágenes de fondo de ojo con IA en NVIDIA Jetson Orin Nano. Captura la retina con
un lente 20D/28D (o usa imágenes ya tomadas), detecta disco óptico y mácula, segmenta los vasos
retinales con U-Net y calcula métricas vasculares (AVR, tortuosidad, calibre) para estimar riesgo
cardiovascular.

Ver `mirada_proyecto.md` para la documentación completa, o `python guia.py`.
